A partir de este momento, asumirás el rol de un ingeniero de software senior, arquitecto de aplicaciones macOS y especialista en administración, diagnóstico, seguridad y optimización de sistemas Apple, con más de 20 años de experiencia equivalente.

Tus especialidades incluyen:

* Desarrollo nativo para macOS.
* Swift, SwiftUI, AppKit y Objective-C.
* Arquitectura de software profesional.
* Administración del sistema de archivos APFS.
* Gestión de almacenamiento y aplicaciones.
* Diagnóstico de rendimiento.

* Seguridad, permisos y protección del sistema.
* Diseño UI/UX de aplicaciones premium.
* Optimización para procesadores Apple Silicon.
* Distribución de aplicaciones mediante archivos DMG y PKG.
* Pruebas automatizadas, depuración y mantenimiento.

No actuarás únicamente como programador. Serás responsable de investigar, diseñar, desarrollar, probar, corregir y empaquetar una aplicación completamente funcional.

2. CONTEXTO DEL PROYECTO

Quiero desarrollar una aplicación de escritorio para mi MacBook Pro con procesador Apple M2 y 256 GB de almacenamiento.

La aplicación será un centro de administración, limpieza, diagnóstico y optimización de macOS.

Nombre provisional: MacGuardian.

El nombre podrá cambiar posteriormente.

La aplicación será exclusivamente para uso personal.

Requisitos generales:

* Compatible con mi versión actual de macOS.
* Optimizada para Apple Silicon M2.
* Completamente en español.
* Interfaz gráfica moderna y profesional.
* Funcionamiento principalmente local y sin conexión a Internet.
* Sin suscripciones.
* Sin compras integradas.
* Sin publicidad.
* Sin recopilación de datos personales.
* Sin cuentas de usuario.
* Sin servicios externos innecesarios.
* Sin procesos permanentes que consuman recursos injustificadamente.
* Sin dependencias comerciales.
* Instalación mediante un archivo DMG o PKG.

Prioriza Swift y SwiftUI para conseguir una aplicación verdaderamente nativa.

Utiliza AppKit u otros frameworks oficiales cuando sea necesario.

No utilices Electron salvo que puedas demostrar una ventaja técnica significativa que justifique su consumo adicional de recursos.

MÓDULO 3 — LIMPIEZA INTELIGENTE

Desarrolla un sistema que identifique archivos potencialmente innecesarios.

Debe analizar:

* Cachés de usuario.
* Registros antiguos.
* Archivos temporales.
* Instaladores DMG.
* Instaladores PKG.
* Archivos ZIP antiguos.
* Descargas olvidadas.
* Archivos residuales.
* Cachés de navegadores.
* Archivos temporales de aplicaciones.
* Datos de desarrollo regenerables.
* Archivos de compilación obsoletos.
* Elementos de la Papelera, únicamente cuando sea posible hacerlo de forma segura y autorizada.

Clasifica los resultados en tres niveles:

VERDE — Generalmente seguro

Archivos regenerables identificados con suficiente certeza y cuya eliminación no debería afectar datos personales ni sesiones activas.

AMARILLO — Requiere revisión

Archivos que podrían contener datos importantes o afectar temporalmente el funcionamiento de una aplicación.

ROJO — Protegido

Archivos del sistema, datos personales sensibles, bases de datos activas y cualquier elemento cuya eliminación pueda provocar pérdida de información o inestabilidad.

Los archivos protegidos no podrán eliminarse desde el limpiador automático.

Antes de ejecutar cualquier limpieza, muestra:

* Nombre del archivo.
* Ruta.
* Tamaño.
* Aplicación relacionada.
* Motivo por el que se considera innecesario.
* Riesgo de eliminarlo.
* Posibilidad de recuperación.
* Espacio estimado recuperable.

Nunca elimines archivos automáticamente sin autorización explícita.

Prioriza mover los elementos a la Papelera cuando sea técnicamente posible.

No prometas que eliminar cachés aumentará necesariamente el rendimiento.

MÓDULO 4 — DESINSTALADOR COMPLETO

Quiero poder administrar y desinstalar las aplicaciones instaladas en mi Mac.

El módulo debe identificar aplicaciones en ubicaciones como:

* /Applications
* ~/Applications
* Otras ubicaciones autorizadas por el usuario.

Presenta:

* Icono.
* Nombre.
* Versión.
* Desarrollador.
* Tamaño.
* Ubicación.
* Fecha de última utilización, cuando esté disponible.
* Archivos relacionados.
* Servicios asociados.
* Estado de ejecución.

Desinstalación profunda

Cuando seleccione una aplicación, busca archivos asociados en ubicaciones relevantes, como:

* Application Support.
* Preferences.
* Caches.
* Containers.
* Group Containers.
* Saved Application State.
* LaunchAgents.
* LaunchDaemons.

Utiliza identificadores de paquete, metadatos y otras evidencias verificables para asociar archivos con aplicaciones.

No relaciones archivos únicamente porque tengan nombres parecidos.

Distingue claramente entre:

1. Archivos exclusivos de la aplicación.
2. Archivos compartidos.
3. Datos personales creados con la aplicación.
4. Archivos cuya pertenencia es incierta.

Los archivos compartidos, datos personales y elementos ambiguos deberán conservarse por defecto.

Antes de desinstalar:

* Mostrar todos los elementos encontrados.
* Permitir seleccionar cuáles eliminar.
* Calcular el espacio estimado.
* Advertir sobre posibles pérdidas de configuración.
* Solicitar confirmación.

Implementa también un detector de restos de aplicaciones previamente desinstaladas.

Importante: No intentes eliminar aplicaciones protegidas por macOS ni evadir System Integrity Protection.

Cuando una aplicación requiera su propio desinstalador, indícalo y ofrece abrirlo.

No prometas desinstalar absolutamente cualquier aplicación cuando existan restricciones del sistema.
